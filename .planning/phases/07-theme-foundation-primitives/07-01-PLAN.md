- Define a React Context `ThemeModeContext` holding a value of type `{ mode: ThemeMode }` (import `ThemeMode` from `@/components/shared/tokens`).
- Export a `ThemeProvider({ children }: { children: React.ReactNode })` component.

- The return type is the `lightTheme`/`darkTheme` object shape — do not invent new keys, do not re-declare the shape.
