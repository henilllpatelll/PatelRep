Create `apps/mobile/lib/theme/ToastProvider.tsx`:

Context + state:
- Define `type ToastVariant = "success" | "error" | "info";` and `type ToastState = { id: number; variant: ToastVariant; message: string } | null`.
- Create a React Context exposing `{ show: (variant: ToastVariant, message: string) => void }`.
- `ToastProvider({ children })` holds `const [toast, setToast] = useState<ToastState>(null)` and a monotonically increasing `idRef` (useRef). `show(variant, message)` sets `{ id: ++idRef.current, variant, message }` — this REPLACES any current toast (D-03, no queue). Memoize the context value with `useMemo`. Render `<ToastContext.Provider value={value}>{children}</ToastContext.Provider>` — the Provider does NOT render the viewport itself (the viewport is mounted separately in the layout so it can be positioned relative to OfflineBanner). Expose the current `toast` + a `dismiss()` setter through the same context (or a second context) so `ToastViewport` can read them.

Export `ToastViewport({ topOffset }: { topOffset: number })`:
- Reads the current `toast` and `dismiss` from context. Renders `null` when `toast` is null.
- Colors via `useTheme()`: `success` → `theme.status.ready`; `error` → `theme.status.dirty`; `info` → `theme.shell.bg`. Icon (Ionicons) + text are `#FFFFFF`. Icon names: success `checkmark-circle`, error `alert-circle`, info `information-circle`, size 18.
- Auto-dismiss timer keyed on `toast.id` (useEffect with `[toast?.id]`): success/info after 3000ms, error after 5000ms. Clear the timer on cleanup/replace.
- Enter animation: `Animated.Value` translateY from `-20`→`0` and opacity `0`→`1` over 200ms ease-out on mount/id-change. Exit (timeout or swipe past threshold): translateY `0`→`-20`, opacity `1`→`0` over 150ms ease-in, then call `dismiss()`. Use core RN `Animated` ONLY — no Reanimated (Pitfall 3).
- Swipe-to-dismiss: `PanResponder` on horizontal drag; if `|dx| > 80` on release, run the exit animation and dismiss. Tapping does nothing (D-04 — not interactive; do not wrap in a touchable that dismisses on press).
- Container style: `position: "absolute"`, `top: topOffset`, `left: 12`, `right: 12` (the `marginHorizontal: 12` from spec), high `zIndex` (e.g. 1000). Inner card: `borderRadius: 12` (`R.md`), `paddingHorizontal: 16`, `paddingVertical: 12`, `flexDirection: "row"`, `alignItems: "center"`, `gap: 12`, `backgroundColor` = variant fill, `shadowColor: "#000"`, `shadowOpacity: 0.18`, `shadowRadius: 10`, `shadowOffset: { width: 0, height: 4 }`, `elevation: 6`. Text: `color: "#FFFFFF"`, `fontSize: 15`, `fontWeight: "600"`, `numberOfLines={2}` — DO NOT truncate to one line (ES strings run 15–30% longer, Pitfall 4). Keep static layout in `StyleSheet.create`; pull only the variant `backgroundColor` inline from `useTheme()`. Style merge order for the outer container: `style={[styles.base, animatedStyle]}` (base first).
- The `message` prop is rendered verbatim — the Toast NEVER calls `t()` (D-04, caller owns translation). No hardcoded English default text anywhere.

Create `apps/mobile/lib/theme/useToast.ts`:
