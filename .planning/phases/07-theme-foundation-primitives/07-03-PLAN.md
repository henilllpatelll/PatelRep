Create `apps/mobile/components/ui/Button.tsx` as a `Pressable`-based primitive.

Props:
```ts
type ButtonVariant = "primary" | "secondary" | "ghost" | "destructive";
type ButtonSize = "sm" | "md" | "lg";
interface ButtonProps {
  label: string;                 // caller-provided, already translated — NO default
  onPress: () => void;
  variant?: ButtonVariant;       // default "primary"
  size?: ButtonSize;             // default "md"
  loading?: boolean;
  disabled?: boolean;
  icon?: React.ComponentProps<typeof Ionicons>["name"];
  style?: StyleProp<ViewStyle>;
}
```
There is NO default label — the caller always supplies an already-translated string (Pitfall 4 / i18n floor contract). Never call `t()` inside this file.

Colors via `const theme = useTheme();` (resolve at render, inline — keep static layout in `StyleSheet.create`). Variant color map (EXACT values):
| variant | bg (default) | text/icon color | pressed |
|---|---|---|---|
| primary | `theme.primaryAction` | `#FFFFFF` | bg → `theme.primary` |
| secondary | `theme.surface`, border 1px `theme.border` | `theme.textPrimary` | bg → `theme.surfaceMuted` |
| ghost | `transparent`, no border | `theme.primaryAction` | bg → `theme.primarySoft` |
| destructive | `theme.status.dirty` | `#FFFFFF` | dim fill to `opacity: 0.85` |

For `destructive` pressed feedback, apply `opacity: 0.85` on press rather than a hardcoded darker hex — this honors the codebase's `activeOpacity` 0.84–0.85 convention (HeroButton/WorkOrderCard) and avoids inlining a non-token status hex (Pitfall 9). All other variants swap `backgroundColor` to the mapped pressed token via `Pressable`'s `style={({ pressed }) => ...}`.

Size map (EXACT — all meet the ≥44 touch-target floor via minHeight, no hitSlop needed):
| size | minHeight | paddingHorizontal | fontSize | iconSize | borderRadius |
|---|---|---|---|---|---|
| sm | 44 | 12 | 14 (weight "600") | 14 | 12 (`R.md`) |
| md | 48 | 16 | 15 (weight "600") | 16 | 12 (`R.md`) |
| lg | 56 | 24 | 16 (weight "600") | 18 | 12 (`R.md`) |

Disabled: `opacity: 0.4`, no press feedback. `loading` implies `disabled`.

Loading state (D-07, NO layout shift): render the label `<Text>` with `opacity: 0` (so it still reserves its intrinsic width/height) and absolutely position an `<ActivityIndicator size="small" />` centered over it. Spinner color = the variant's foreground color (`#FFFFFF` for primary/destructive, `theme.primaryAction` for secondary/ghost). Do not change the button's size/position between idle and loading.

Layout: `flexDirection: "row"`, `alignItems: "center"`, `justifyContent: "center"`, `gap: 8` (icon-to-label). If `icon` is set and not loading, render `<Ionicons name={icon} size={iconSize} color={fg} />` before the label.

Style merge order (LOCKED, Pitfall 6): `style={[styles.base, variantStyle, sizeStyle, props.style]}` — base first, variant, size, caller `style` LAST.

Do NOT import `C`, `lightTheme`, or `darkTheme` directly — colors come ONLY through `useTheme()` (the enforceable boundary).
