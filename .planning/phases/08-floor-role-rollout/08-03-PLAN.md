## C.* → theme.* map + Button/useToast signatures: see 08-02-PLAN.md (identical). Import:
`import { useTheme } from "@/lib/theme/useTheme"; const theme = useTheme();`
`import { useToast } from "@/lib/theme/useToast"; const toast = useToast();`
