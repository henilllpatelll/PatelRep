<objective>
Stand up the Playwright pixel-diff regression harness that captures pre-redesign baseline screenshots of the 3 excluded Room Board surfaces (RoomStatusBoard, RoomDetailDrawer, EngineeringRoomBoard) in light and dark mode for two real roles, and re-checks them for zero drift. This is FOUND-03 — the deepest safety guarantee of the whole v2.0 milestone; per the requirement it must be captured BEFORE any token/primitive work begins. Runs in Wave 1 so the baseline reflects the untouched tree.

Purpose: Every later phase (30-04 tokens onward, Phases 31-36) re-runs this diff to prove the excluded boards never visually drift. It must be trustworthy enough to leave wired into CI on every PR — which means an unchanged tree must render BYTE-IDENTICALLY, so the diff can distinguish "a frozen primitive drifted" from ordinary data change. A live production board (rooms getting cleaned, statuses flipping) can never satisfy `maxDiffPixelRatio: 0`; masking only covers chrome, not which rooms exist or their status colors. Therefore this plan pins a deterministic, never-operated fixture data source.
Output: A seed script + committed baseline snapshot set + a regression config/spec any phase can run.
</objective>
