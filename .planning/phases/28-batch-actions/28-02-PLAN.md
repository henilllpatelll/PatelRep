  <action>
In `apps/api/models/requests.py`, add:
```python
class BatchAcknowledgePredictionsRequest(SanitizedBaseModel):
    prediction_ids: List[UUID4] = Field(min_length=1, max_length=50)
```
Cap 50, same rationale as Plan 28-01 (matches the room-readiness batch cap; keep the two batch caps consistent).

In `apps/api/routers/assets.py`, add `POST /failure-predictions/batch-acknowledge` -> `batch_acknowledge_failure_predictions(body: BatchAcknowledgePredictionsRequest, current_user=Depends(require_role("gm","engineer")))`. Gate is `require_role("gm","engineer")` ONLY — mirror the single-item gate at assets.py:114 exactly; do NOT add `chief_engineer` (LOCKED decision — see 28-CONTEXT.md "Resolved during phase research").

The handler MUST:
- Loop `body.prediction_ids`, calling `await acknowledge_failure_prediction(prediction_id=str(pid), current_user=current_user)` per id inside its own `try/except HTTPException`. Do NOT reimplement the update; do NOT add a bulk `.in_()` pre-fetch.
- CRITICAL not_found handling (this domain differs from room-readiness): the single-item `acknowledge_failure_prediction` (assets.py:116-125) does a tenant-scoped `.update().eq("id",...).eq("tenant_id",...)` and returns `{"data": result.data[0] if result.data else None}` — it does NOT raise 404 for a missing/cross-tenant id, it returns `{"data": None}` with a 200. So the batch loop must inspect each call's return: if the returned `data` is falsy/None, record `{"prediction_id": pid, "action": "not_found"}` (a per-item failure, PITFALL #6 — a cross-tenant/missing id must NOT be silently counted as an acknowledged success). If `data` is present, record `{"prediction_id": pid, "action": "acknowledged"}`. A raised `HTTPException` becomes `{"prediction_id": pid, "action": "error", "status": e.status_code, "detail": e.detail}`.
- Return `{"data": {"results": [...], "succeeded": <count where action=="acknowledged">, "failed": <count of not_found + error>}}`, one entry per requested id, order preserved.

Regenerate the RBAC matrix if the drift-guard test fails (`python apps/api/scripts/generate_rbac_matrix.py`).
