ROLE GATING (Pitfall #7 — required): compute `const allowed = getAllowedHrefs({ role, customRoleModules, frontDeskModules: hotel?.front_desk_modules ?? null })` and gate EACH entity fetch behind its route so a role never queries an entity it can't reach:

- Work Orders group only if `allowed.includes('/engineering')`
- Guest Requests group only if `allowed.includes('/guest-requests')`
- SOPs group only if `allowed.includes('/sop')`
Use `enabled:` on each useQuery so gated-off entities fire zero network calls.

PER-ENTITY FETCH (per 31-RESEARCH Pattern 3 endpoint table):
- Rooms — CLIENT-SIDE: `roomsApi.list()` already returns ALL tenant room_status rows (≤~150). Fetch once (cache), then substring-filter on `rooms.room_number` client-side. No q param.
- SOPs — CLIENT-SIDE: `sopApi.listDocuments()` returns ALL SOP docs. Substring-filter on `title` (+ optionally `category`) client-side. No q param.
- Work Orders — SERVER q (from 31-03): `engineeringApi.listWorkOrders({ q: term, per_page: 5 })` — the `q` → title ilike is required because the endpoint is paginated (client-side over one page would miss records).
- Guest Requests — SERVER q (from 31-03): `guestRequestsApi.listRequests({ q: term, per_page: 5 })`.
Cap each group to ~5 results. Every call reuses the client's existing tenant scoping — role/tenant filtering comes for free; do NOT add any tenant param.

- Room → `router.push('/housekeeping?room=' + room_id)` (existing FROZEN RoomStatusBoard deep-link — confirmed at RoomStatusBoard.tsx:212,336; zero new frozen-file code)
- Work Order → `router.push('/engineering/work-orders?focus=' + id)` (31-03)
- Guest Request → `router.push('/guest-requests?focus=' + id)` (31-03)
- SOP → `router.push('/sop?focus=' + id)` (31-03)
Show a per-entity secondary line (e.g. room number + status, WO/guest title, SOP category). Handle loading (per-group spinner) and empty ("no matches") states. Preserve the existing Enter-selects-first behavior — decide a sensible ordering (nav matches first, then rooms, then the rest) so Enter hits the most likely target.
