```ts
interface StateBlockProps {
  status: "loading" | "empty" | "error";
  children?: React.ReactNode;                              // rendered when data is present (caller decides)
  // empty:
  emptyIcon?: React.ComponentProps<typeof Ionicons>["name"];
  emptyTitle?: string;                                     // caller-provided (required in practice for empty)
  emptyBody?: string;
  // error:
  errorIcon?: React.ComponentProps<typeof Ionicons>["name"];  // default icon name "alert-circle-outline"

  retryLabel?: string;                                     // caller-provided translated label (e.g. t("common.retry"))

}
```
The component NEVER calls `t()` and has NO hardcoded English strings (Pitfall 4, D-04). The only non-string defaults allowed are Ionicons name fallbacks (icon names, not user copy).

- Otherwise (caller signals data is present): render `{children}`.

Colors via `useTheme()`. Style merge order (LOCKED): base first, caller `style` last. Do NOT import `C`/`lightTheme`/`darkTheme`.
