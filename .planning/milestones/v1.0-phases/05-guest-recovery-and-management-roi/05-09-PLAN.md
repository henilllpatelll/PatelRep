<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| staff browser → guest SMS send | A UI action that transmits text to a third party's phone |
| staff browser → guest message history | Guest PII (message bodies, reply content) rendered on screen |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-09-01 | Elevation of Privilege | Unauthorized role texting a guest | mitigate | The reply box renders only when `canReply` matches the API's `MESSAGE_ROLES` set; the server's 403 remains the authoritative control |
| T-05-09-02 | Tampering | Contacting a guest who has opted out | mitigate | The reply box is disabled inline when `contact_opted_out_at` is set, with an explanatory message; the API's 422 consent gate is the backstop. UI-SPEC forbids a confirm-dialog pattern here, so there is no "send anyway" path |
| T-05-09-03 | Information Disclosure | Guest phone number displayed in the thread | mitigate | The drawer never renders `recipient` or `guest_phone`; it sends no recipient at all and relies on the server-side fallback |
| T-05-09-04 | Information Disclosure | Guest message content leaking into AI features | mitigate | Messages are fetched through the dedicated endpoint only; `excluded_from_ai` remains TRUE on every row and no AI component consumes this query key |
| T-05-09-05 | Repudiation | A failed send appearing to have succeeded | mitigate | Every outbound bubble carries its `effective_delivery_status` pill sourced from the append-only delivery-event chain, and `failure_reason` is rendered when present |
| T-05-09-06 | Elevation of Privilege | Guidance panel becoming an implicit room-assignment control | mitigate | D-15 constrains this to information only; enforced by an acceptance criterion that the panel contains no `onClick`, `<Button`, or `useMutation` |
| T-05-09-07 | Information Disclosure | Cross-tenant accessible-room data | mitigate | `GET /guest-requests/accessibility/features` is tenant-scoped server-side; the client sends no tenant identifier |
</threat_model>
