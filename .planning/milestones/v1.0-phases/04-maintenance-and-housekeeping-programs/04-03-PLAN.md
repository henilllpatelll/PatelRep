<objective>
Slice 0 defensibility fixes (G2, G4, G8, D-07). Reuse the Phase 1/2 append-only `operational_audit_events` machinery — no parallel audit mechanism. Three gaps: (G2) neither deferral approval nor failed-check containment writes an audit event; (G4) deferrals self-approve (`requested_by == approved_by == current_user`), making approval meaningless; (G8) corrective work orders write no audit, set no `due_at` (so the escalation cron never picks them up), and use `urgent` even for life-safety failures.

Purpose: A completion record must prove actual work, and a failed check must produce containment + an audited, escalatable follow-up (Phase 4 exit criteria).
Output: Distinct-approver deferral flow with audit, and corrective-WO hardening (due_at, criticality-based priority, containment audit).
</objective>
