- [K-8980d6cbd1 · L732] **Opera "Delimited Data" export structural quirks, confirmed on 2 real downloaded samples (`res_detail_*.txt` = Reservation Detail/arrivals, `gibyroom_*.txt` = Guests INH-By Room/in_house), see `apps/api/services/opera/report_parser.py` + `report_columns.py`:** some free-text fields (`BILL_TO_ADDRESS`, `COMPANY_NAME`) contain a **raw, unescaped embedded newline with zero quoting**, splitting one logical record across 2-3 physical lines — a naive line-by-line reader shreds these. Solved both generically (no per-report config needed) with a relative threshold: accumulate physical lines until the running tab count reaches ~70% of the header's tab count, then split as one record.
